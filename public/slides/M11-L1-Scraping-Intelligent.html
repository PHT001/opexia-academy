Les 5 sources de données B2B

🌏

Google Maps

Entreprises locales, téléphone, adresse, avis clients. Outil : Outscraper (version gratuite disponible).

💼

LinkedIn

Décideurs, postes, entreprises, connexions. Outil : PhantomBuster. La source la plus riche pour le B2B.

📈

Annuaires professionnels

Sociétés, SIREN, dirigeants, chiffre d’affaires. Outil : Pappers API. Données officielles fiables.

🏠

Sites web d’entreprises

Pages À propos, équipes, emails de contact. Outil : Apify. Variable selon le site.

🚀

Job boards

Entreprises qui recrutent = signal d’achat fort. Croissance = budget = besoin de services IA.

Le workflow en 5 étapes

1

Définir ton ICP

Profil de Client Idéal. Ex : « Restaurants > 20 avis Google, dans un rayon de 50 km, avec un site web mais sans réservation en ligne. »

2

Collecter les données brutes

Outscraper pour Google Maps, PhantomBuster pour LinkedIn. Paramètre bien les filtres : localisation, catégorie, avis minimum.

3

Nettoyer et qualifier avec l’IA

Envoie les données à Claude pour nettoyer, dédupliquer, normaliser et attribuer un score de qualification 1-10.

4

Enrichir les profils

L’IA visite le site web de chaque prospect : technologies utilisées, taille d’équipe, problèmes potentiels à résoudre.

5

Exporter la liste finale

Google Sheet ou CRM. Chaque ligne contient toutes les infos pour une approche personnalisée.
