C’est quoi un chatbot custom ?

💬

Pas juste ChatGPT

Un assistant spécialisé qui connaît le business, les produits et les services du client.

📚

RAG

Retrieval-Augmented Generation : on donne des documents de référence au modèle pour des réponses précises.

🎯

Réponses fiables

Le chatbot répond avec les vraies données du client, pas des hallucinations.

RAG = chercher l’info pertinente dans une base, puis la donner au modèle avec la question. Résultat : réponse précise et fiable.

OpexIA Academy

L’architecture en 4 étapes

1

L’utilisateur pose une question

Le frontend envoie la question à ton API Route Next.js.

2

Recherche dans la base

Ton API cherche les documents pertinents (FAQ, fiches produits, etc.).

3

Envoi à Claude API

La question + les documents trouvés sont envoyés à Claude pour générer une réponse.

4

Réponse en streaming

La réponse s’affiche mot par mot dans l’interface de chat.

Le prompt système : le secret

Exemple de system prompt

« Tu es l’assistant du cabinet dentaire Martin à Lyon.
Tu réponds uniquement sur : horaires, tarifs, prise de RDV, urgences.
Ton ton est professionnel et rassurant.
Si tu ne connais pas la réponse, dis : «Contactez-nous au 04 XX XX XX XX».
Ne réponds JAMAIS sur des sujets médicaux. »

Le system prompt définit la personnalité, les limites et le ton. C’est 80% de la qualité du chatbot.
