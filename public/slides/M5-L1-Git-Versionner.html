Les 3 zones de Git

📁

Working Directory

Ton dossier de travail. Les fichiers que tu modifies au quotidien. Git les surveille mais ne les sauvegarde pas encore.

📦

Staging Area

La zone de préparation. Tu choisis quels fichiers seront inclus dans le prochain commit avec git add.

🔒

Repository

L’historique sécurisé. Chaque git commit crée un point de sauvegarde permanent. Impossible à perdre.

Pense à Git comme un Ctrl+Z infini pour tout ton projet. Tu peux revenir à n’importe quel moment passé.

Les commandes essentielles

1

git init

Initialise Git dans ton projet. À faire une seule fois au début du projet.

2

git status

Vérifie l’état de tes fichiers : modifiés, ajoutés, prêts à commiter. Utilise-la tout le temps.

3

git add .

Ajoute tous les fichiers modifiés dans la Staging Area. Le point signifie « tout ».

4

git commit -m "message"

Crée un point de sauvegarde avec une description. Le message explique ce que tu as fait.

5

git push

Envoie tes commits sur GitHub. Ton code est maintenant sauvegardé dans le cloud.
