Les permissions : garde le contrôle

🔎

Lire des fichiers

Claude Code lit ton code pour comprendre le contexte. Toujours autorisé par défaut.

✏

Modifier des fichiers

Il te montre le diff avant d’appliquer. Tu valides ou tu refuses chaque modification.

⚙

Exécuter des commandes

npm install, git commit... Il demande la permission avant d’exécuter.

Règle d’or : Lis toujours le diff avant d’accepter. C’est ton filet de sécurité.

Le workflow pro

1

Travaille dans un dossier projet

Toujours à la racine du projet, jamais dans un dossier aléatoire. Claude a besoin de voir la structure.

2

Initialise Git

git init avant de commencer. Tu peux revenir en arrière à tout moment avec git checkout.

3

Commence petit

Fichier HTML, modification de texte, ajout de CSS. Augmente la complexité progressivement.

4

Lis ce que Claude fait

Il affiche les fichiers modifiés et les commandes exécutées. Lis avant d’accepter.
