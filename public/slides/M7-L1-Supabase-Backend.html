SQL : les 4 commandes essentielles

🔍

SELECT

Lire des données.
SELECT * FROM clients

➕

INSERT

Ajouter des données.
INSERT INTO clients (...)

✏

UPDATE

Modifier des données.
UPDATE clients SET ...

🗑

DELETE

Supprimer des données.
DELETE FROM clients WHERE ...

Tu n’as pas besoin de maîtriser le SQL. Claude Code écrit les requêtes pour toi.

OpexIA Academy

Auth en 3 lignes

🔒

Inscription

supabase.auth.signUp({ email, password })
L’utilisateur reçoit un email de confirmation automatiquement.

🔑

Connexion

supabase.auth.signInWithPassword({ email, password })
Session gérée automatiquement avec des cookies sécurisés.

🎯

OAuth (Google, GitHub)

supabase.auth.signInWithOAuth({ provider: ’google’ })
Login social en 1 ligne. L’utilisateur clique et c’est fait.
