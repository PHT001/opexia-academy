Régler la voix comme un pro

🎧

Stabilité : 0.5 – 0.7

Trop bas = voix imprévisible. Trop haut = voix monotone. Le juste milieu pour un agent pro.

🎨

Similarité : 0.75

Reste fidèle au modèle de voix original. Résultat cohérent et professionnel.

💫

Style : 0.3 – 0.4

Légèrement expressif sans être dramatique. Idéal pour un contexte business.

Pour un usage commercial, utilise les voix de bibliothèque (libres de droits).
