Les composants : la brique de base

1

Un composant = une fonction

Une fonction JavaScript qui retourne du JSX (du HTML amélioré). Header, bouton, formulaire — tout est un composant.

2

Réutilisables

Tu crées un composant Button une fois, tu l’utilises partout. Un changement = mis à jour partout.

3

Les props = les paramètres

Tu passes des données à tes composants : <Card title="Mon titre" />

4

Le state = la mémoire

Le state stocke les données qui changent : formulaire, compteur, menu ouvert/fermé.

HTML vs JSX

HTML classique
JSX (React)
class="header"
Attribut class
className="header"
className en React
onclick="maFonction()"
Événement en string
onClick={maFonction}
Fonction directe
Fichiers .html séparés
Pages statiques
Composants .tsx
Interface dynamique
